FOUNDATION

What is Blockchain?

Understand the fundamental ideas behind distributed and decentralized systems.

Blockchain

A blockchain is a distributed ledger that records transactions or data in linked blocks across a network of computers.

Decentralization

Instead of depending on one central system, a network can distribute data and validation across multiple participants.

Cryptography

Cryptographic techniques help protect data, verify information and support secure transactions and identities.

HOW IT WORKS

Important Blockchain Concepts

Understand the technology before building blockchain applications.

Blocks

A block contains a collection of records or transactions together with information that helps connect it to the blockchain.

Transactions → Block → Hash

Hashing

A hash is a fixed-length output generated from data. Blockchain systems use hashes to help identify and connect data.

Data → Hash Function → Hash

Consensus

Consensus mechanisms provide ways for participants in a distributed network to agree on the state of the ledger.

Network → Validation → Agreement

Smart Contracts

Smart contracts are programs deployed on blockchain networks that execute according to programmed conditions.

User → Contract → Blockchain
