Command Line

Essential Linux Commands

Start building your terminal confidence with commonly used commands.

Files & Directories

pwd Show current directory
ls List files
cd Change directory
mkdir Create directory
touch Create file
rm Remove files

File Operations

cp Copy files
mv Move or rename
cat Display file content
less Read files
grep Search text
find Find files

Permissions

chmod Change permissions
chown Change ownership
whoami Current user
sudo Run with privileges

System & Processes

ps View processes
top Monitor processes
df Disk usage
free Memory usage

Learning Path

Linux Roadmap

Follow this sequence from beginner to professional-level Linux skills.

01

Computer & OS Fundamentals

Understand operating systems, hardware, files, processes and basic networking.

02

Linux Fundamentals

Install Linux and become comfortable with the desktop and terminal.

03

Linux Commands

Practice navigation, file management, text processing and system commands.

04

Users, Groups & Permissions

Learn ownership, permissions, sudo, users and groups.

05

Networking & SSH

Learn IP addresses, ports, DNS, network commands and remote access.

06

Shell Scripting

Automate repetitive tasks using Bash scripts and command-line tools.

07

Servers & Services

Practice web servers, services, logs, storage and system administration.

08

Linux + Cloud + DevOps

Connect Linux knowledge with Docker, Kubernetes, cloud and DevOps workflows.
