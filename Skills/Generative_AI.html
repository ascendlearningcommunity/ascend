How Generative AI Applications Work

From User Input to AI Output

Understand the basic flow of a modern generative AI application.

01

User Input

The user provides a question, instruction or other input.

02

Prompt

The application structures the input into a suitable prompt.

03

AI Model

The model processes the prompt and generates an output.

04

Application Output

The application presents the generated result to the user.
