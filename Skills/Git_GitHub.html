FOUNDATION

What are Git & GitHub?

Understand the tools developers use to track, manage and collaborate on software projects.

Git

Git is a distributed version control system used to track changes in source code and manage different versions of a project.

GitHub

GitHub is a cloud platform where developers store Git repositories, collaborate on projects, review code and manage development work.

Version Control

Version control helps developers maintain project history, recover previous versions and safely work on new features.

ASCEND TIPS

How to Learn Git & GitHub

Focus on practicing real workflows instead of memorizing commands.

Create a small project and use Git from the first line of code.

Make meaningful commits instead of putting the entire project into one commit.

Practice creating and merging branches regularly.

Learn how to understand and resolve merge conflicts safely.

Maintain a clean GitHub profile with useful README files and project descriptions.

Practice pull requests and code reviews with classmates or teammates.

Do not just memorize commands — understand what happens to your project after each command.

Build projects and use GitHub as a public portfolio of your development work.

Build. Commit. Collaborate. 🚀

Start using Git and GitHub with your next ASCEND project and develop professional version-control habits.
